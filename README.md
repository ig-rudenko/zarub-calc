## О проекте

**ZarubCalc** — инженерный финансовый калькулятор для точного расчёта и наглядного сравнения двух способов пополнения зарубежной карты Visa в сервисе **zarub.io** из рублей:

1. **Способ 1 — Напрямую через СБП в zarub.io**:
   - Оплата в рублях по внутреннему курсу USD сервиса (по умолчанию `101,50 ₽/$`, редактируется вручную).
   - Фиксированная комиссия СБП **`7%`** (минимум `1 ₽`).
   - Комиссия перевода с внутреннего кошелька Zarub на карту Visa **`1.5%`**.

2. **Способ 2 — Через покупку криптовалюты на whitebird.io по СБП**:
   - Покупка криптовалюты за рубли по СБП (курс по умолчанию `82,37 ₽/USDT`, доступна автозагрузка биржевого курса и ручной ввод).
   - Поддержка четырёх направлений с индивидуальными тарифами:
     - **GRAM (Сеть TON)** _(по умолчанию)_: комиссия Whitebird `2.5%`, сеть блокчейн `0 GRAM`, комиссия Zarub `3%` (мин. `$1`, округление вверх до целого `$`), курс `1 GRAM ≈ $0,84`.
     - **USDT (Сеть TRON TRC-20)**: комиссия Whitebird `2.5%`, сеть блокчейн `2,16763 USDT`, комиссия Zarub `3%` (мин. `$1`, округление вверх).
     - **USDT (Сеть TON)**: комиссия Whitebird `3.2%`, сеть блокчейн `0 USDT`, комиссия Zarub `5%` (мин. `$1`, округление вверх).
     - **TRX (Сеть TRON)**: комиссия Whitebird `3.2%`, сеть блокчейн `0,263 TRX`, комиссия Zarub `3%` (мин. `$1`, округление вверх), курс `1 TRX ≈ $0,28`.
   - Финальный перевод с баланса кошелька Zarub на карту Visa с удержанием **`1.5%`** ($B = \lceil C / (1 - 0{,}015) \rceil_{0{,}01}$).

## Ключевые возможности

- **Три режима расчёта**:
  - **На карту Visa ($)** — сколько рублей потребуется заплатить по факту, чтобы на карте оказалась точная чистая сумма в долларах (например, для `$100,00` на карте автоматически рассчитывается необходимые `$101,53` на кошельке Zarub).
  - **На баланс Zarub ($)** — расчёт пополнения внутреннего кошелька с отображением суммы, которая дойдёт до карты после удержания `1.5%`.
  - **Бюджет в рублях (₽)** — обратный расчёт от фиксированной суммы в рублях.
- **История и динамика курсов в `localStorage`**:
  - Для каждого типа курса (`USD в Zarub`, `USDT в Whitebird`, `TRX в Zarub`, `GRAM в Zarub`) ведётся отдельная история изменений со временем, мини-графиком динамики (SVG Sparkline), выбором сохранённого значения в один клик и удалением тестовых записей.
- **Визуализация потерь и комиссий**:
  - Кольцевые SVG-диаграммы (Donut) и линейные шкалы, разделяющие полезную ценность на карте, комиссии сервисов, сетевые сборы блокчейна и переплату за внутренний курс.
- **Светлая и тёмная темы оформления** с сохранением выбора пользователя.

## Деплой на GitHub Pages

В проекте уже настроены относительные пути сборки (`base: './'` в `vite.config.ts`) и готовый пайплайн GitHub Actions (`.github/workflows/deploy.yml`).

Для включения автоматической публикации на GitHub Pages:

1. Загрузите репозиторий на GitHub (ветка `main`).
2. Перейдите в настройки репозитория: **Settings → Pages**.
3. В разделе **Build and deployment → Source** выберите **GitHub Actions**.
4. При каждом пуше в ветку `main` workflow автоматически запустит тесты `Vitest`, соберёт проект (`npm run build`) и опубликует папку `dist/` на GitHub Pages.
